# Company AI v8.0.0 — Core Build Completion

## Purpose
Complete and verify the core company operating layer while keeping launch/deployment work explicitly deferred.

## Added
- Operational workflow engine with step advancement and completion.
- Customer 360 view connecting permitted CRM, project, task, order, invoice, ticket, proposal and notification records.
- Notification inbox/read state with recipient enforcement.
- Operational report generation for management.
- Core completion audit endpoint that lists implemented business areas and verified capabilities.
- Extended executive/operational layer without changing owner-only protected actions.

## Governance
- Binding contracts remain owner-only.
- Protected orders remain owner-locked.
- Company money-out operations remain blocked for AI/staff.
- Standard pre-approved sales remain executable under the central permission engine.

## Explicitly deferred
- Domain, hosting, production deployment, production database cutover, payment gateway activation, external channel activation and production legal configuration remain launch-stage work.
